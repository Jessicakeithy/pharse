# ⚡ Gerador de Citações

> Uma aplicação interativa desenvolvida com HTML5, CSS3 e JavaScript puro, focada em manipulação de DOM, estilização moderna e design responsivo.

## 🛠️ Tecnologias Utilizadas

O projeto utiliza os fundamentos principais do desenvolvimento Front-end web:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** 
  * Padrão de fundo pontilhado em CSS puro (`radial-gradient`).
  * Layout flexível com `Flexbox` e alinhamento via `gap`.
  * Efeito de brilho neon no título (`text-shadow glow`).
  * Animação contínua de gradiente na faixa superior (`keyframes`).
  * Tipografia customizada (*Quicksand*).
* **JavaScript (Vanilla):**
  * Manipulação dinâmica de elementos do DOM.
  * Estruturação de dados com *Arrays*.
  * Lógica de sorteio procedural com `Math.random()` e `Math.floor()`.
  * Manipulação de eventos de clique (`addEventListener`).

---

## ✨ Funcionalidades

* 🎲 **Sorteio Dinâmico:** Gera frases motivacionais instantaneamente ao clicar no botão.
* 🎨 **Visual Moderno & Cozy:** Combinando fundo neutro pontilhado com destaques em Azul Capri e Lilás.
* 📱 **Responsividade Total:** Adaptado para celulares, tablets e desktops.
